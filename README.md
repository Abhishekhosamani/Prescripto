# Prescripto 🏥

Prescripto is a full-stack doctor appointment booking platform that enables patients to find doctors, book appointments, and manage healthcare interactions.

🚧 This project is currently under development, with upcoming AI-powered features.

---

## 🚀 Features

* User authentication (JWT-based)
* Doctor listing & profiles
* Appointment booking system
* Admin dashboard

---

## 🛠️ Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: JWT

---

## 📁 Project Structure

prescripto/
├── backend/
├── frontend/
├── admin/

---

## ⚙️ Setup

1. Clone the repository
   git clone https://github.com/your-username/prescripto.git

2. Install dependencies
   cd backend && npm install
   cd frontend && npm install
   cd admin && npm install

3. Add `.env` files

4. Run the project
   Backend → npm run server
   Frontend/Admin → npm run dev
